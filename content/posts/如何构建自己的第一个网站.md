### 如何构建自己的第一个网站？



### 🚀 一键搭建教程（手把手）

#### 第一步：Fork 模板仓库

- 打开这个模板：https://github.com/adityatelange/hugo-PaperMod
- 点右上角 `Fork`，创建到你自己的 GitHub 仓库

#### 第二步：创建 Cloudflare Pages 项目

1. 登录 Cloudflare → 打开“Pages”
2. 点击“Create a Project”
3. 连接你的 GitHub → 选择你 Fork 的 `hugo-PaperMod` 仓库
4. 设置构建信息如下：
   - **构建命令（Build command）：** `hugo`
   - **输出目录（Output folder）：** `public`
   - **环境变量（Environment Variables）：**
     - `HUGO_VERSION` → `0.121.1`（最新版可查：https://github.com/gohugoio/hugo/releases）

#### 第三步：部署成功之后设置你的自定义域名

1. Cloudflare Pages 项目主页 → Custom Domains → 添加你已经在 Cloudflare 注册好的域名
2. 自动设置 DNS 记录（或者手动设置 `CNAME`）

#### 第四步：编辑内容（本地或者 GitHub 上直接改）

- 内容都在 `content/` 目录下，可以写 `.md` 文件来添加新笔记
- 修改网站信息在 `config.yml` 或 `config.toml` 文件中配置



### 🧠 小贴士

- 想加搜索功能？开启 `Fuse.js` 搜索支持（PaperMod 有现成配置）
- 想部署 Markdown 生成的 API 文档？可以嵌入 Swagger UI、ReDoc 等插件
- 也可以改成博客风格 + 笔记分类，自由度很高



## 📚 如何编辑内容（超重要）

你只需要会写 Markdown，就可以轻松管理你整个网站的所有笔记，以下是具体操作步骤：

------

### 1️⃣ 所有笔记都放在 `content/posts/` 目录下

- 每篇文章是一个 `.md` 文件（Markdown 文件）
- 命名建议用英文或拼音，比如：`linux-basic.md`

------

### 2️⃣ 每篇文章的格式（YAML 头部 + 正文）

```
markdown复制编辑---
title: "Linux 基础入门"
date: 2025-04-14
tags: ["Linux", "操作系统"]
categories: ["系统基础"]
---

这是我的第一篇 Linux 学习笔记！

## 常用命令

```bash
ls -la
cd /etc
yaml复制编辑
📌说明：
- `title`：文章标题
- `date`：文章时间（格式必须正确）
- `tags` 和 `categories`：可以用来自动生成分类页面
- 下方就是你写的内容，Markdown 支持标题、图片、代码块等

---

### 3️⃣ 图片怎么插入？

图片放在 `/static/images/` 目录下，Markdown 中这样引用：

```markdown
![示例图片](/images/linux.png)
```

你也可以放远程图片，不过建议图片都用本地管理。

------

### 4️⃣ 添加新文章的步骤（本地 or GitHub 编辑都行）

#### ✅ 方法一：直接在 GitHub 上添加 `.md` 文件

1. 打开 `content/posts/` 目录
2. 点 “Add file” → “Create new file”
3. 命名为 `xxx.md`，写上 Markdown 内容 → 提交即可自动部署

#### ✅ 方法二：在本地写好后推送到 GitHub

1. 克隆仓库到本地
2. 写好 `.md` 文件 → 放到 `content/posts/` 下
3. 执行 `git add . && git commit -m "新增笔记" && git push`
4. Cloudflare 会自动部署！

## 🌐 最后：添加自定义域名

Cloudflare Pages 后台里：

- 点进你的网站 → “Custom domains”
- 添加你已有的域名（比如 `note.xxx.com`）
- 设置好 DNS（通常自动帮你配好）
